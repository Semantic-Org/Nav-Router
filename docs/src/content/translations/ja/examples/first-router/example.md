`routes` がアプリのすべてです。最上位のルートがレイアウトを持ち、`index` は `/` のページ、`member` は `:userId` パラメーターを受け取ります。レイアウトにはページが入る場所として `<slot>` を書き、`href()` がルートの名前とパラメーターから各リンクを組み立てます。

リンクはただのアンカーです。ブラウザー自身の `navigate` イベントをルーターが捕捉するので、リンク用のコンポーネントは存在せず、リンクごとに配線するものもありません。
