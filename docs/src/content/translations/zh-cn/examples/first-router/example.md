`routes` 就是整个应用：根路由持有布局，`index` 是位于 `/` 的页面，`member` 接收一个 `:userId` 参数。布局在页面要出现的位置写一个 `<slot>`，`href()` 则根据路由名称及其参数生成每个链接。

这些链接都是普通的锚点。路由器捕获的是浏览器自身的 `navigate` 事件，所以不需要链接组件，也不用为每个链接单独接线。
